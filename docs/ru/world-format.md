# Формат мира и сохранений

[English](../en/world-format.md) · Русский

Пользовательских данных три вида: файлы карт (поставляются с игрой),
сохранения миров (пишет игра) и `settings.json` (пишут настройки). Всё это
обычный текст, поэтому сломанное сохранение можно открыть и починить руками.

## Где лежат файлы

| Файл | ПК | Android |
|---|---|---|
| `assets/map.txt`, `assets/basement.txt` | проект / рядом с бинарником | упакованы в APK |
| `worlds/manifest.json` | `./worlds/` от рабочего каталога | внутренние данные приложения |
| `worlds/world_{id}.json` | `./worlds/` | внутренние данные приложения |
| `settings.json` | `./settings.json` | внутренние данные приложения |

`core::asset` скрывает разницу: `load_bytes` читает ассеты проекта (на Android
через `AAssetManager`, отрезая префикс `assets/`), а `save_data` / `load_data` /
`delete_data` всегда работают с каталогом пользовательских данных.

`worlds/` и `*.json` перечислены в `.gitignore`; `settings.json` лежит в
репозитории как дефолт, но в рантайме всё равно перезаписывается.

## Файлы карт

Карта — сетка токенов через пробел, один токен на клетку. Строка `j`
соответствует миру `y = WORLD_OFFSET_Y - j`, столбец `i` — `x = WORLD_OFFSET_X + i`
(`WORLD_OFFSET_X = -26`, `WORLD_OFFSET_Y = 14`). То есть первая строка — верх
карты, а `y` растёт вниз по файлу.

```
grass      . @ * m f ~ l H K 1 2 3 4 5 6
floor      P Q Z X , _ A D 0
wall       = - h d ^ & W S [ ] : ; o % q p i
grass edge / | ( { ) }
door       E
```

- Токены травы выбирают кадр атласа `assets/tex/map/grass.png` (`[col, row]`
  в атласе 4×6); сезон меняет файл текстуры, а не кадр.
- Токены пола — из `floor.png` (атлас 3×3), стены — из `wall.png` (5×5).
  Стены пересчитываются при добавлении и сносе объектов
  (`recompute_wall_token`), поэтому нарисованные руками углы — только
  начальное состояние.
- `E` — анимированная дверь магазина: атлас 2×2, свой кадр на клетку,
  `Z_DOOR = Z_DECOR`.
- Неизвестный токен молча становится обычным полом. За известным набором
  следит тест `every_map_token_resolves_to_an_in_bounds_atlas_frame`.

Проходимые клетки считает `load_walkable_cells` по тем же токенам: стена
непроходима, пол и дверь — проходимы.

## Манифест миров

`worlds/manifest.json` — индекс в стиле Minecraft. `next_id` только растёт,
id не переиспользуются, а список при показе сортируется по `updated`.

```json
{
  "next_id": 3,
  "worlds": [
    {
      "id": 0,
      "name": "Shop",
      "created": 1760000000,
      "updated": 1760003600
    }
  ]
}
```

Имена уникальны: `create_world_with_name` при совпадении добавляет `(1)`,
`(2)`, а пустое имя превращается в `Мир`.

## Сохранение мира

`worlds/world_{id}.json` пишет `GameScene::save_to_disk` — при выходе, по
`Ctrl+S` и при возврате в меню. Это полный снимок, а не дифф.

```json
{
  "levels": {
    "0": {
      "map_grid": [[".", "."], [".", "."]],
      "original_tokens": [],
      "objects": []
    }
  },
  "current_level": 0,
  "money": 150,
  "total_food": 0,
  "slots": ["box", "sign", "rack", "table", "cassa"],
  "act_slot": 0,
  "mode": 0,
  "camera_offset_x": 0.0,
  "camera_offset_y": 0.0,
  "map_size": 0.6,
  "active": true,
  "basement_placed": false,
  "busy_cassas": [],
  "shop_owned": []
}
```

| Поле | Смысл |
|---|---|
| `levels` | id уровня → снимок (`0` магазин, `1` подвал) |
| `map_grid` | текущие токены по клеткам, чтобы перестроенные стены и пол выжили |
| `original_tokens` | `[x, y, token]` клеток, изменённых относительно исходной карты |
| `objects` | поставленные объекты: имя, клетка, еда, максимум еды, флаг ковра |
| `current_level` | какой уровень загружать первым |
| `money`, `total_food` | ресурсы экономики |
| `slots`, `act_slot`, `mode` | хотбар, активный слот, текущий режим |
| `camera_offset_x/y`, `map_size` | позиция камеры и зум |
| `active` | магазин открыт/закрыт |
| `basement_placed` | построен ли вход в подвал |
| `busy_cassas` | кассы, занятые покупателями (восстанавливаются свободными) |
| `shop_owned` | купленные товары (`#[serde(default)]`, старые сохранения читаются) |

Битый или отсутствующий файл мира заставляет `load_from_disk` вернуть `false`;
игра начинает свежий уровень вместо падения. Неизвестные поля JSON `serde`
игнорирует, а отсутствующие необязательные подставляет по умолчанию.

## Настройки

`settings.json` живёт отдельно от миров: он относится к приложению, а не к
сохранению.

```json
{
  "vsync": true,
  "zoom_speed": 0.08955699,
  "music": true,
  "sfx": true
}
```

| Поле | По умолчанию | Смысл |
|---|---|---|
| `vsync` | `true` | present mode `Fifo` против `Mailbox` |
| `zoom_speed` | `0.1` | шаг зума колесом и щипком |
| `music` | `true` | фоновая музыка |
| `sfx` | `true` | звуковые эффекты |

Файл перезаписывается при каждом изменении настроек и при выходе. Отсутствующий
или нечитаемый файл молча заменяется на `GameSettings::default()`.

## Совместимость

- Новое поле с `#[serde(default)]` оставляет старые сохранения читаемыми;
  обязательное поле их ломает. По умолчанию — `default`.
- `map_grid` хранит токены, а не объекты редактора: если убрать токен из
  `token_to_texture`, старые сохранения нарисуют его как обычный пол.
- Источник правды для списка миров — `worlds/manifest.json`. Удалённый руками
  `world_{id}.json` оставляет пункт в меню, который загрузится как новый мир.
- `next_id` никогда не выводится из существующих файлов, поэтому восстановление
  старого манифеста может дать дубли id. Храните манифест вместе с мирами.
