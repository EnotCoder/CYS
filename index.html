Create your Shop (CYS)

Game where you have to set up your own shop
PRE-ALPHA STAGE
View on GitHub

Hello everyone! This is my first 2D game that I made using the wgpu API.

For now, it is my favorite project. I use winit for window management and wgpu for rendering graphics.

The game is in pre-Alpha stage, and I'm actively developing it!

Repository: github.com/EnotCoder/CYS

🎮 Game Features

Grid-Based Building

Place and remove objects on a large map with precise positioning. Build your dream shop!

Multiple Modes

Switch between Standard (interact), Build, and Delete modes for different actions

Food System

Boxes auto-generate food. Click to collect, click rack to stock. Feed your customers!

Shopper NPCs

Customers spawn at the entrance, pick food from a rack, pay at the cassa, and leave. Watch your shop come alive!

Active Toggle

Toggle NPC spawning on/off with a click. Close the shop when you need to restock!

Carpet System

Decor objects can only be placed on carpets - strategic placement required!

Mouse & Keyboard

Scroll to zoom, WASD/arrows to pan, click to interact, and intuitive key bindings

Smart Fences

Fences auto-connect to neighbors with dynamic textures. Create enclosures effortlessly!

Inventory System

Press E to open inventory with categorized tabs (Objects, Carpets, Wall Decor). 25 slots!

🖱️ Controls

Mouse Move Move cursor (hover over tiles)
F Build/Delete (depends on mode)
Tab Cycle modes (Standard → Build → Delete)
Q Switch inventory slot
K / L Zoom in / out
Mouse Scroll Zoom in / out
E Open/close inventory
I Toggle tooltip visibility
G Interact (collect food from box / fill rack)
Click Interact with mode icon / active toggle

🔄 Game Modes

Standard Mode (0)

Default cursor - no building action. Navigate and plan your shop layout.

Build Mode (1)

Green/Red cursor - place objects from active slot. Red means invalid position.

Delete Mode (2)

Delete cursor - remove objects under cursor from your shop.

⚠️ Known Limitations

• Map is fixed at 40x29 tiles (loaded from map.txt)
• Objects cannot be placed outside walkable tiles
• Decor objects require a carpet underneath (red/green/blue carpet, etc.)
• Wall decor (welcome sign) can only be placed on wall tiles (@)
• Only one building object per cell
• NPC pathfinding is simple A* - may not find optimal routes in complex layouts

📋 Recent Updates

Shopper NPCs

• NPC shoppers spawn, walk to rack, queue at cassa, pay, and leave
• Per-cassa busy tracking allows multiple checkout counters
• Active toggle to open/close the shop
• Money counter (+5 per purchase)
• 3 second spawn interval, max 3 concurrent shoppers

Food & Economy

• Boxes auto-generate food over time
• Click box to collect food into reserve
• Click rack to stock it from reserve
• Shoppers take food from rack and pay at cassa

Inventory & Objects

• Full inventory system with 3 tabs (Objects, Carpets, Wall Decor)
• 18+ placeable objects including fence, ice cream, arcade machine
• Smart fences with neighbor-aware textures
• Tooltip system (press I to toggle)
• Frustum culling for performance
