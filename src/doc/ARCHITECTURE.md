# Архитектура проекта (CYS)

Файловая система исходников организована по принципу движка Godot:
в папке `src/` ровно 12 основных папок.

```
src/
├── main/        — точка входа приложения (main.rs — корень крейта, App, winit-цикл)
├── core/        — «ядро»: wgpu-пайплайн, текстуры, рендер; константы и утилиты
├── scenes/      — сцены: menu, game (level, day/night, HUD, shoppers)
├── ecs/         — ECS: adapter, компоненты, фабрика, группы, спрайты, курсор
├── data/        — данные: Slot/Object, размещение (placement), карта (map)
├── ui/          — интерфейс: компоненты, хотбар, инвентарь, настройки, текст
├── input/       — ввод: камера, курсор, взаимодействие
├── npc/         — логика покупателей (ShopperNpc)
├── audio/       — звук (rodio: клики, музыка)
├── scripts/     — Lua-мост (баланс config.lua, скрипты npc.lua)
├── doc/         — документация
└── tests/       — юнит-тесты
```

Ассеты (`tex/`, `sounds/`, `scripts/*.lua`, файлы карт `*.txt`) лежат в корне
проекта и в папку `src/` не входят.

## Слои рендера (z-order)
`Z_MAP=0.0` → `Z_CARPET=1.0` → `Z_DECOR=1.5` → `Z_NPC=2.0` → `Z_CURSOR=2.5` → `Z_UI=3.0`

## Карта
`src/data/map/` — загрузка карты из `map.txt`/`basement.txt` в ECS
(`mod.rs`) и поиск пути A* для NPC (`pathfinding.rs`).
