# Скрипты (scripts/)

Папка `scripts/` содержит два вида файлов:
- **игровые Lua-скрипты** — читаются движком через Lua-мост (`src/scripts/`):
  `config.lua` (баланс) и `npc.lua` (поведение покупателя);
- **dev-инструменты** — `gen_sounds.py` (генератор звуков).

Игровых Lua циклов в движке нет: каждый файл выполняется один раз —
`config.lua` при старте (в `BalanceConfig::load`), `npc.lua` вызывается
пофункционально из `ShopperNpc`.

---

## config.lua — баланс игры (единый конфиг)

**Что реализует:** единственный источник всех балансовых параметров.
Читается движком один раз при старте в `BalanceConfig`
(`src/scripts/config.rs::load`). Покупатель (`npc.lua`) читает те же
значения через глобаль `CONFIG`, поэтому баланс правится в одном месте.

Если файл отсутствует или повреждён — используются дефолты из Rust,
игра не падает.

### Секции и роль в игре
| Параметр | Реализация |
|---|---|
| `shopper_spawn_interval`, `shopper_spawn_cooldown`, `max_shoppers` | Частота и лимит спавна покупателей (`ShopperManager::tick`) |
| `food_regen_tick`, `food_regen_amount` | Регенерация еды в ящике (`update` в `GameScene`) |
| `day_cycle_secs`, `day_secs`, `night_start_secs`, `night_secs`, `fade_secs` | Цикл день/ночь и затемнение мира (`day_night.rs`) |
| `npc_speed`, `walk_anim_interval`, `npc_fade_speed` | Скорость и анимация покупателя (`ShopperNpc`) |
| `spawn_x`, `spawn_y` | Точка спавна и выходная дверь магазина |
| `cassa_wait_secs`, `candy_wait_secs` | Сколько покупатель стоит у кассы/конфет (оплата) |
| `money_at_cassa`, `money_at_candy`, `candy_chance` | Доход с продаж и вероятность «зайти за конфетами» |
| `max_food_box`, `max_food_rack`, `max_food_candies`, `candies_start_food` | Вместимости хранилищ и стартовый запас конфет |
| `box_tex_threshold_1`, `box_tex_threshold_2` | Пороги смены текстур коробки по остатку еды |
| `start_money`, `rent_amount`, `rent_interval_secs` | Стартовый капитал, аренда и её период (банкротство) |
| `object_prices` (`table`) | Переопределение цен объектов; остальные берут цену из `Object.price` |
| `font_path` | Путь к файлу шрифта (применяется при перезапуске) |

## npc.lua — поведение покупателя (ShopperNpc)

**Что реализует:** всю логику принятия решений покупателя сверх Rust-примитивов:
переходы между состояниями, тайминги ожидания и выбор маршрута.
Примитивы низкого уровня (`walk`, `take_food`, `set_busy`, `add_money` …)
реализованы в Rust и вызываются из Lua через объект `npc`.

Состояния (зеркало `ShopperState` из `src/npc/mod.rs`):
`1 GoingToRack` → `2 GoingToCassa` → `3 AtCassa` → `4 GoingToCandies` →
`5 AtCandies` → `6 GoingToExit`.

### Жизненный цикл покупателя
1. Спавн → идёт к стеллажу (`rack`);
2. берёт еду (`take_food`) и бронирует кассу (`set_busy`);
3. идёт к кассе → платит (`add_money` за еду) → освобождает кассу;
4. с шансом `candy_chance` идёт к конфетам → берёт → платит;
5. уходит к выходу (`spawn_x/spawn_y`) → `despawn`.

### Обработка аварийных ситуаций
- Касса удалена по пути → переключение на другую кассу или уход;
- стеллаж удалён/пуст до взятия еды → деспавн;
- магазин закрыт (`npc.exiting`) → покупатель без корзины уходит;
- магазин снова открыт → разворот обратно к `rack`;
- касса занята другим покупателем → ожидание очереди;
- конфеты удалены/кончились → пропуск и уход.

## gen_sounds.py — генератор звуковых эффектов (dev-инструмент)

**Что реализует:** синтезирует 8-битные звуковые эффекты в стиле текущих
`sounds/*.ogg` чистым Python (стандартная библиотека) через WAV + ffmpeg
в OGG. Запуск: `python3 scripts/gen_sounds.py`.

Генерируемые эффекты: `click`, `hover`, `error`, `bell`, `cash`,
`pickup`, `candy`, `stair`, `save`. Складываются в `sounds/`.
